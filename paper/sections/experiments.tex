\subsection{Protocol gates}
The protocol file \texttt{strict\_evaluation\_v1.json} is frozen before the
full evaluations. It forbids test labels from codec fitting, signal-quantizer
fitting, codec operating-point selection, alarm baseline construction, alarm
score calibration, and alarm threshold selection. A fixed random seed is
used only for the declared bootstrap procedure. Historical E2--E4 scripts
remain repository diagnostics; their outputs are not used for selection and
are not paper results.

\subsection{E7: strict codec benchmark}
E7 applies all four codecs to the date-separated OGW split. Candidate
configurations are first filtered by a proven per-record bound and then
selected using healthy validation data as specified in Section~3. The four
capacities are all reported, rather than reducing the result to one chosen
point. The primary outcome is held-out record ROC AUC for D04 and D24, with
serialized payload summaries, decoder model bytes, and temperature-matched
checks retained in the audit JSON.

\subsection{E8: cold-start alarm audit}
E8 calibrates both feature families on the complete healthy March 2021
month. The predeclared threshold grid contains the 0.90, 0.95, 0.975, 0.99,
0.995, 0.9975, 0.999, 0.9995, and 0.9999 quantiles of March calibration
scores. April is fully scored before its labels are accessed. The paper
reports the range over all nine thresholds for each feature, not a threshold
selected after inspecting false calls, delay, or coverage.
